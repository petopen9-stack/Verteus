# Verteus Contracts

NEAR smart contracts for the Skill Registry, Leasing, and Rarity.

## Planned Contracts

- `skill_registry` — register, update, transfer skills
- `skill_lease` — time-based leasing with escrow
- `rarity_oracle` — (initially simple scoring, later more sophisticated)
- `auction` — optional Dutch / English auction for high-rarity skills
