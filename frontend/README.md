# Verteus Frontend

Next.js app for discovering, listing, leasing, and composing skills.

## Planned Pages

- `/` — Discover rare skills
- `/skills/[id]` — Skill detail + lease/buy
- `/list` — List a new skill
- `/dashboard` — My skills / leases / earnings
- `/compose` — Compose multiple skills into a new agent
